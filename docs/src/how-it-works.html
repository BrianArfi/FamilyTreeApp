From one sheet to a tree the whole family can open

1

Google Sheet

One row per person: name, gender, born, father, mother, spouses.

2

Apps Script web app

GET returns everyone as JSON.

POST adds, edits or deletes a row, if the password is right.

3

Layout engine

Generation = how many parents up. Couples side by side, lines drawn.

4

Your family

VIEWEveryone browses

Scroll the tree, open any member.

EDITAdmin only

Add, edit, delete with the password.

Admin saves: POST {action, password, data} Your Apps Script checks the password, writes the sheet, and the tree reloads.
